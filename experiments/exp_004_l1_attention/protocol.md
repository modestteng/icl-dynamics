# 第一层注意力的只读阶段分析

日期2026-10-04。复用exp_002原20M基线，不使用exp_003的筛选后模型。

依据主要论文5.1节、附录图14/附录C.4，以及作者`visualize_runs.make_forward_fn`、`update_all_token_layer_attention_over_time`和`coopetition_paper_appendix_plots.ipynb`单元36–41。继承先前缺少implement-research-code时允许独立最小适配的授权，作者源代码不改。

四组固定评价数据：train_eval、icl、iwl_copy_avail、flip_icl，各原5000条，不采样、不生成新数据。在检查点0、1M、2M、3M、4.4M、6M、8M、10M、12M、16M、20M上做原模型前向。沿用float32/default矩阵精度与原权重，无干预或训练。

输入顺序为[x1,y1,x2,y2,xq]。attention矩阵行是关注者/query位置，列是被关注者/key位置；每行和为1，未来位置被因果mask屏蔽。

按图14分别测8个头，只看两个标签位置：

- previous-token attention `P=(A[1,0]+A[3,2])/2`；
- attending-to-self `S=(A[1,1]+A[3,3])/2`。

上述使用0起索引；论文的标签位置2/4就是这里1/3。先在正确标签处于上下文第一个/第二个位置的两组内各求均值，再对两组各赋1/2权重，复用作者绘图标准。完整矩阵也按同样条件平衡；保留未平衡均值、每组数量、sample0矩阵与逐序列P/S值。

展示阶段0/2M/4.4M/8M/20M的完整5x5矩阵，全部8个头，不按好看结果更换头。动态曲线使用上述11个检查点的实测点；连线仅连接实测点。

本分析的明确判据：在4.4M时P>S、20M时S>P，并且P下降、S上升的头，具有从previous-token dominance到self dominance的观察性转换；这不是论文给出的硬阈值，也不是因果证明。另报告P/S变化与差值，不强求所有头满足。排除x1位置只能看自身的结构性注意力，避免把整个对角线均值当作机制判据。

保存原配置/固定评价/源文件/检查点/分析脚本哈希；核对attention有限、范围/行和/因果mask/张量形状，与作者聚合实现一致。阶段行为准确率重新计算，仅与原日志核对，不替代原行为结果。曲线与注意力矩阵只能支持模式变化，不能独立证明L1导致能力切换或L2子电路语义复用。
